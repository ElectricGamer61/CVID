_Written 2026-07-01. Read this first, then `docs/context/architecture.md` for how the app works._

`frontend/src/App.tsx`) as the primary editing surface, **drop the vendored FreeCut editor**, make

## Plan — 4 phases (one per session: implement → verify → commit → handoff)

### Phase 1 — Shelve FreeCut, restore old editor
Remove FreeCut wiring; leave `editor/` on disk unused.
- `frontend/vite.config.ts`: drop `/editor` proxy + COOP/COEP headers (keep only `/api`).
- `frontend/src/Sidebar.tsx`: remove `studio` icon + "Editor" nav item + `onStudio` prop.
- `frontend/src/App.tsx`: remove `{name:"studio"}` route, `goStudio`, `NAMED.studio`, sbView entry,
  `onStudio` prop, the `route.name==="studio"` render clause, and the `Studio()` iframe fn.
- `backend/app/main.py`: remove the `_corp_header` CORP middleware (only FreeCut needed it).
- `.claude/launch.json`: remove the `editor` (port 5173) block.
- **Keep** `build_edit` / `/api/tickets/{tid}/build-edit` (feeds the OLD editor).
- Verify: `cd frontend && npm run build` = 0 errors; no `/editor/*` 404s; clip click opens ClipEditor.

### Phase 2 — Bug fixes + audit
1. **Reel rebuild wipes edits** (`main.py` `build_edit`): if the Clip already has edits
   (`cuts_json`/`words_json`) and scene count is unchanged, **preserve** start/end/cuts/words/style/
   voiceover; only refresh markers. If beats changed → wipe but return `{"reused_edits": false}` so
   the UI can toast.
2. **Voiced-scene duration lock — REAL fix** (chosen): a trim on a voiced scene must actually
   shorten output. In `assemble.py` `render_scene_reel`, when a scene is trimmed shorter than its VO,
   trim/clamp the VO audio to match (don't loop video to VO length). Keep loop-to-VO only when the
   scene is longer than the VO.
3. **Transient split → persist for real** (chosen): add `Clip.splits_json` (mirrors `cuts_json`) +
   `_migrate` entry + `ClipPatch.splits` + `EditDoc.splits: number[]`; replace local `splitMarks`
   state with `doc.splits`. Splits then survive reload + get undo/redo free.
4. **Audit pass** (mandatory): drive the editor via preview MCP (trim/cut/clips/subtitles/voice on a
   clip; per-scene record/trim/delete on a reel), check console + network + backend logs after each;
   log every finding; surface anything beyond these 3 bugs before fixing.

### Phase 3 — Descript-style transcript editor
Build the stubbed `{ id: "text", soon:true }` tool in `TOOLS`. **Reuses `doc.cuts`** — no new cut
storage; the backend `remap_words_for_cuts`/`render_clip_segments` already do the cut→render work.
- New helper `annotateWordsWithCuts(words, cuts)` (keeps ALL words tagged `cut:bool`, unlike
  `remapWords` which drops them) + `subtractRange(cuts,[a,b])` for restore.
- New `TranscriptEditor` component: flowing word-spans; active word highlighted; cut words
  struck-through but selectable; click word → seek; select range + Delete → add cut; select cut
  range + Delete → restore. Default: clamp selection to cut boundaries (no mixed selection).
  `onCutsChange={(cuts)=>set({cuts})}` → flows through `useHistory` (undo/redo free).
- Rename tool label "Text" → "Transcript". Word-text editing stays in the Subtitles tab.
- Verify interop: transcript delete ↔ Cut/Clips/timeline all reflect the same `doc.cuts`; export
  drops the words.

### Phase 4 — Submagic AI auto-effects (opt-in, one panel / three checkboxes)
Single "✨ AI Effects" panel; nothing changes unless clicked. Order: emphasis/emoji → zoom → SFX.
- Extract `ai.py` LLM dispatch → `backend/app/pipeline/llm.py`; new `effects.py` with
  `suggest_emphasis`/`suggest_zoom_keyframes`/`suggest_sfx` (one shared analysis, fail-safe empty).
  New endpoint `POST /api/clips/{cid}/ai-effects` runs only checked sub-effects.
- **4a Emphasis+emoji**: additive keys on word dicts in `words_json` (`emphasis?`, `emoji?`) — no
  schema change. Render in `CaptionOverlay.tsx` + backend `build_ass`. **Spike early:** confirm
  libass rasterizes emoji via the wired Windows fonts dir; PNG-overlay fallback if not.
- **4b Punch-in zoom**: new `Clip.effects_json` (`{zoom:[{t,scale,duration}],sfx:[...]}`) +
  `_migrate` + `ClipPatch.effects`. Keyframes in source time; add `remap_keyframes_for_cuts` in
  `render.py` (share `to_edited()`). Export: `zoompan` AFTER the aspect-crop+face-center (composes,
  never re-picks crop). Preview: CSS `transform: scale()` keyed to editedTime.
- **4c SFX**: bundle ~6-8 royalty-free Mixkit/Pixabay SFX at `backend/assets/sfx/` (+
  `frontend/public/sfx/` for preview). Store in `effects_json.sfx`; export mixes via ffmpeg
  `adelay`+`amix` into the existing audio/VO mux. Fully skippable (unchecked = identical output).
- Guarantee: a never-clicked clip renders byte-identical to Phase 3 (opt-in).
